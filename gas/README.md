# 線上訂單串接 Google Sheet：部署教學

網站結帳後，訂單會自動寫進 Google 試算表，並寄出顧客確認信和門市新訂單通知。整個流程不需要伺服器，也不需要付費。

```
顧客在網站結帳 → Google Apps Script（網頁應用程式）→ Google 試算表
                                 ├─ 寄訂單確認信給顧客
                                 └─ 寄新訂單通知給總部／門市
```

---

## 一、建立試算表與程式（約 5 分鐘）

1. 打開 [Google 試算表](https://sheets.google.com)，新增一份空白試算表，命名為「麥穗鍋貼所 線上訂單」。
2. 上方選單選「**擴充功能 → Apps Script**」。
3. 刪掉編輯器裡原本的程式碼，把這個資料夾裡 **`Code.gs`** 的全部內容貼上，按「儲存」（磁碟片圖示）。
4. （建議）左側「專案設定」⚙️ →「時區」選 **(GMT+08:00) 台北**。
5. 上方函式選單選 **`setup`**，按「**執行**」。
   - 第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。這是因為程式要讀寫你自己的試算表、幫你寄信，是正常的。
6. 回到試算表，會看到這幾個工作表：

| 工作表 | 用途 |
|---|---|
| **訂單** | 一筆訂單一列。在「狀態」欄用下拉選單更新進度 |
| **訂單明細** | 每個品項一列，方便統計銷量 |
| **菜單** | 品項代碼、名稱、價格、是否上架。**後端以這裡的價格計算金額** |
| **門市** | 可填各門市自己的「新訂單通知 Email」 |
| **設定** | 暫停接單、通知信箱、運費、免運門檻 |
| **每日統計** | 自動彙整每天的訂單數與營業額（不含已取消） |

## 二、部署成網頁應用程式

1. Apps Script 編輯器右上角「**部署 → 新增部署作業**」。
2. 左側齒輪「選取類型」→「**網頁應用程式**」。
3. 設定：
   - 說明：`線上訂單 v1`
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/……/exec`）。

> 「所有人」的意思是網站訪客可以**送出訂單**，但看不到你的試算表。試算表仍然只有你（和你分享的人）能打開。

## 三、把網址填進網站

打開 `index.html`，找到這一行：

```js
const ORDER_API_URL = '';
```

把剛剛複製的網址貼在引號中間，存檔後推送到 `main` 即可。也可以直接把網址傳給 Claude，請它幫你填好並上線。

**還沒填網址時**，網站是「示範模式」：可以結帳，但訂單不會送出。

## 日常使用

### 處理訂單
在「訂單」工作表的「**狀態**」欄用下拉選單更新：

`新訂單` → `製作中` → `可取餐`／`已出貨` → `已完成`（或 `已取消`）

改成 **可取餐、已出貨、已取消** 時，如果顧客有填 Email，系統會自動寄信通知（同一個狀態只會通知一次）。「狀態更新時間」也會自動記錄。

### 暫停接單
「設定」工作表把「接單」改成 **關**，網站結帳就會顯示「目前暫停線上接單」。改回 **開** 即可恢復。

### 修改價格／下架商品
- 改「**菜單**」工作表的「單價」，或取消勾選「上架」。
- 網站上顯示的價格寫在 `index.html` 裡，**兩邊要一起改**。
- 如果兩邊價格不一致，訂單會照試算表的價格計算，「金額檢查」欄會出現「⚠ 不一致」提醒你。

### 新增商品
在「菜單」新增一列，「品項代碼」要和 `index.html` 裡的 `id` 一樣（例如 `p5`）。

## 更新程式後要重新部署

如果之後修改了 `Code.gs`：

**部署 → 管理部署作業 → 選擇現有部署 → ✏️ 編輯 → 版本選「新版本」→ 部署**

這樣網址不會變，網站不用改。（如果用「新增部署作業」，會產生新網址。）

## 限制與注意事項

- **寄信額度**：一般 Gmail 帳號每天約 100 封，Google Workspace 帳號約 1,500 封。超過時訂單仍會正常寫入，只是不會寄信。
- **線上付款**：選「LINE Pay／信用卡」目前只會記錄顧客的選擇，「付款狀態」預設是「未付款」，不會真的扣款。要真正收款需要另外串接金流（例如綠界、藍新、LINE Pay 官方 API）。
- **個資**：試算表裡有顧客姓名、手機、地址，請不要把試算表設成「知道連結的人都能檢視」。

## 疑難排解

| 狀況 | 解法 |
|---|---|
| 網站顯示「無法連線到訂單系統」 | 確認網址以 `/exec` 結尾，部署時「誰可以存取」選的是「所有人」 |
| 改了程式但沒生效 | 照上面「更新程式後要重新部署」選「新版本」 |
| 狀態改了卻沒寄信 | 確認有執行過 `setup`（會建立觸發器）、顧客有填 Email、「設定」的「狀態變更通知顧客」是「是」 |
| 想看錯誤紀錄 | Apps Script 左側「執行作業」 |
| 想確認後端是否正常 | 直接用瀏覽器打開網頁應用程式網址，看到 `{"ok":true,...}` 就是正常 |
